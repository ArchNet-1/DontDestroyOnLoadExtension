# ArchNet · Dont Destroy On Load Extension

Add this component to keep its GameObject alive when a new scene loads (managers, music player…).

- Unity **6000.0** or newer · No dependency.
- Part of [ArchNet](https://archnet-plateform.fr), free and open-source Unity packages

## Install

*Window > Package Manager > + > Install package from git URL…*

```
https://github.com/ArchNet-1/DontDestroyOnLoadExtension.git
```

## Use

Add **ArchNet > Dont Destroy On Load** to the object. Works on child objects too (they are moved to the root first).
